# Выживи на зарплату

Мобильная экономическая survival-игра о том, как прожить 12 месяцев на обычную зарплату.

Игрок получает доход, оплачивает жильё и повседневные расходы, принимает решения в случайных бытовых событиях, берёт подработки и старается не попасть в финансовую яму.

## Технологии

- Expo SDK 54
- React Native
- Expo Router
- TypeScript
- AsyncStorage для локального сохранения
- Web Audio API для коротких звуковых сигналов в веб-версии

## Запуск

Откройте проект в Expo. Основной режим интерфейса — portrait.

## Игровой цикл

1. Игрок выбирает сложность.
2. В начале месяца получает зарплату.
3. Автоматически оплачиваются обязательные платежи.
4. Игрок открывает случайные события и выбирает решение.
5. В конце месяца переходит дальше.
6. После 12 месяцев показывается финансовый результат.

## Сложности

- Лёгкий — более высокая зарплата и мягкие расходы.
- Нормальный — стандартная экономика.
- Хардкор — меньшая зарплата и более сильное давление расходов.

## Архитектура

- `game/types.ts` — типы игры.
- `game/config.ts` — баланс, месяцы и стартовые значения.
- `game/events.ts` — события, условия и варианты решений.
- `game/engine.ts` — применение эффектов, расходы, переход месяца и сохранение.
- `game/GameContext.tsx` — игровое состояние и действия интерфейса.
- `game/achievements.ts` — достижения и их проверка.
- `game/sound.ts` — звуковые сигналы.
- `components/` — переиспользуемые карточки, кнопки и индикаторы.
- `app/` — экраны меню, игры, достижений и финального результата.

## Добавление событий

Добавьте объект в массив `EVENTS` в `game/events.ts`. Событие содержит заголовок, описание, категорию, условия появления и варианты выбора с эффектами. Новое событие не требует изменения игрового цикла.

## Изменение баланса

Основные параметры находятся в `game/config.ts` внутри конфигураций `easy`, `normal` и `hardcore`.

## Добавление достижений

Добавьте достижение в `ACHIEVEMENTS` и условие разблокировки в `checkAchievements`.

## Изменение текста и графики

Тексты событий и интерфейса находятся рядом с соответствующими экранами и данными. Визуальные элементы игры используют лёгкий flat/cartoon стиль с системными символами, поэтому проект не требует тяжёлых ресурсов.

## Сборка

Веб-версия проверяется через экспорт Expo. Для Android используется стандартная сборка Expo/EAS с package name `com.survivethesalary.game`. Подписывающие ключи в проект не добавляются.

## Сохранение

Состояние игры автоматически сохраняется после изменений. Повреждённое или неподдерживаемое сохранение игнорируется, после чего можно начать новую игру.
